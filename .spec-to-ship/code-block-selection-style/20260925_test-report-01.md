# 测试报告：代码块选中样式修复

日期：2026-09-25

## 改动范围

问题：代码块内选中文字时样式异常——选中带只出现在代码块左右两侧的空白处，选中的文字本身没有高亮；且显示为深石板色块，与浅色主题不符。

定位出两个叠加的根因：

1. **层级遮挡**：`.cm-line.cm-code-line` 的不透明背景 `var(--panel)` 绘制在 CodeMirror `drawSelection` 选区图层（`z-index: -1`）之上，把文字区域的选区矩形整个盖住，只有伸出 `.cm-content` 内容区两侧的部分露出。
2. **深色选中色泄漏到浅色主题**：`app.css` 的 `@media (prefers-color-scheme: dark)` 块未按 `data-theme` 作用域限定，系统深色 + 应用浅色主题（如浅绿色）时选中色被错误覆盖为深色 `#3e5263`（像素采样实测 band 颜色 (63,82,99) 证实）。该媒体块中 `.notice.error`、`.document-name` 存在同类泄漏，一并修正。

修改文件：

- `apps/desktop/src/components/code-block.css:92` 起：代码行背景/边框迁移到 `z-index: -10` 的 `::before` 伪元素（沉到选区图层之下、文字之下），首版 `z-index: -1` 实测无效（选区图层实际 z-index 为 `-1-pos`）。
- `apps/desktop/src/app/app.css:405`：深色媒体查询块改为仅作用于 `:root:not([data-theme])` / `:root[data-theme="system"]`（与 code-block.css 既有约定一致），并为 `[data-theme="night"]` 补充显式深色选中色。
