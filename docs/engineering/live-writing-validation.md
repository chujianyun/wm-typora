# 撰写 / 源码验收

日期：2026-09-05。本次取代此前独立只读预览方案。

- 默认进入撰写模式，同一个 CodeMirror 编辑区内显示 Markdown 排版；仅保留「撰写 / 源码」两个入口。
- 当前光标或选区涉及的块展示原始 Markdown，其他块在原位置渲染。点击已渲染块将光标移到该块开头，直接进入编辑；离开该块恢复排版。列表、表格、代码围栏以整个块为单位。
- 切换模式重配显示扩展，不重建编辑器或正文，不改写保存内容，保留光标及撤销历史。输入法组字期间不执行模式重配。
- Markdown/GFM 支持标题、强调、删除线、引用、列表、任务项、表格、代码块；文档级引用链接定义参与每个块的渲染。原始 HTML 块和引用定义保留字面源码，图片继续使用占位，链接不直接导航。

验证结果：

- Vitest：9 个文件、39 项通过，包括 CRLF、尾随空格及引用定义保真、跨块全选展开、编辑后重新渲染、跨模式撤销与保存。
- Playwright：Chromium / WebKit 共 12 项通过，2 项可选性能采样跳过。覆盖直接点击排版块编辑、离开后更新标题、源码切换、光标与撤销记录、窄窗口表格与长代码、深色模式，以及原有保存和关闭流程。
- TypeScript 生产构建、ESLint、Prettier 检查通过。Vite 仍提示编辑器分块超过 500 kB。
- macOS 调试应用包构建成功：`target/debug/bundle/macos/WTypora.app`。本轮未进行原生桌面输入法或文件系统人工验收，不把浏览器测试视为原生验收。
- 已检查浏览器实际截图：`evidence/live-writing.png`。

当前实现为块级即时渲染；活动块仍展示 Markdown 标记。尚未提供字词级富文本光标映射、可直接操作的表格单元格或任务复选框。超大文档性能未验收。
